## 實機運行截圖

> 執行環境：銀河麒麟高級伺服器作業系統 V11（海光 x86 架構）、RTX 3060，全部為實機錄製，非效果圖。

### 01 · 國產化部署環境

銀河麒麟 V11 檔案總管實拍：`run.sh` / `run_gui.sh` 一鍵啟動腳本，`libcudart` / `libcublas` / `libnvinfer` 執行期元件就位，`livepredict_qt` 主程式與 `.so` 相依齊備。

![部署環境](images/01-deploy.jpg)

### 02 · 圖形介面啟動與模型載入

雙擊 `run_gui.sh` 啟動 Linux Qt 圖形介面，`Linux64_ctc.so` 動態庫即載即用，辨識執行緒載入 14 / 14，GPU(CUDA) 與 CPU 雙後端可切換。

![啟動載入](images/02-launch.jpg)

### 03 · C++ 多執行緒並行推論

14 路並行執行緒同時推論，進度即時滾動，總耗時 463 ms，平均 3 ms/張。

![並行推論](images/03-concurrent.jpg)

### 04 · 即時車號辨識

端到端 C++ 推論，車號 / 貨櫃箱號一次讀出，圖片預覽即時校對。

![辨識結果](images/04-result.jpg)
