## 実機の動作スクリーンショット

> 実行環境：Kylin Advanced Server OS V11（Hygon x86 アーキテクチャ）、RTX 3060。すべて実機で収録したもので、合成画像は含みません。

### 01 · ローカル（国産化）デプロイ環境

Kylin V11 のファイルマネージャーを実写：`run.sh` / `run_gui.sh` のワンクリック起動スクリプト、`libcudart` / `libcublas` / `libnvinfer` ランタイムの配置、`livepredict_qt` 本体と `.so` 依存関係がすべて揃った状態。

![デプロイ環境](images/01-deploy.jpg)

### 02 · GUI 起動とモデル読み込み

`run_gui.sh` をダブルクリックすると Linux Qt GUI が起動し、`Linux64_ctc.so` がその場でロードされます。認識スレッドは 14 / 14 で初期化され、GPU（CUDA）と CPU のバックエンドを切り替えられます。

![起動と読み込み](images/02-launch.jpg)

### 03 · C++ マルチスレッド並列推論

14 スレッドが同時に推論し、進捗がリアルタイムで更新されます。総所要時間 463 ms、平均 3 ms/枚。

![並列推論](images/03-concurrent.jpg)

### 04 · 車番のリアルタイム認識

エンドツーエンドの C++ 推論により、車番／コンテナ番号を一度に読み取り、元画像とその場で照合できます。

![認識結果](images/04-result.jpg)
